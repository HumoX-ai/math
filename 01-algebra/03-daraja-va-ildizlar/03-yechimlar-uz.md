## D. Ratsional ko'rsatkich

### D1
```
8^(1/3) = ³√8 = 2
16^(1/4) = ⁴√16 = 2
27^(2/3) = (³√27)² = 3² = 9
4^(3/2) = (√4)³ = 2³ = 8
32^(−1/5) = 1/(⁵√32) = 1/2
81^(−3/4) = 1/(⁴√81)³ = 1/3³ = 1/27
```

### D2
```
√x = x^(1/2)       ³√(x²) = x^(2/3)       1/√x = x^(−1/2)
⁴√(x⁵) = x^(5/4)   (√x)³ = x^(3/2)
```

### D3
```
x^(1/2) · x^(1/3) = x^(1/2 + 1/3) = x^(3/6 + 2/6) = x^(5/6)
x^(3/4) / x^(1/4) = x^(2/4) = x^(1/2) = √x
(x^(2/3))^(3/2) = x^(2/3 · 3/2) = x¹ = x
(x⁶)^(1/3) = x^(6/3) = x²
```

### D4
```
√x · ³√x = x^(1/2) · x^(1/3) = x^(5/6) = ⁶√(x⁵)

√(x√x) = √(x · x^(1/2)) = √(x^(3/2)) = (x^(3/2))^(1/2) = x^(3/4)
```

### D5
```
(0.001)^(1/3) = ³√0.001 = 0.1                (0.1³ = 0.001 ✓)
(1/16)^(−1/2) = 16^(1/2) = 4                 (ag'dar → ildiz)
0.25^(−1/2) = (1/4)^(−1/2) = 4^(1/2) = 2
(8/27)^(2/3) = (³√(8/27))² = (2/3)² = 4/9
```

### D6 — Isbot
```
Faraz: (aᵖ)^q = a^(pq) qoidasi p = 1/2, q = 2 uchun ham ishlaydi.
Unda:  (a^(1/2))² = a^(1/2 · 2) = a¹ = a.
Demak a^(1/2) — kvadrati a ga teng son. Bunday sonlar: √a va −√a.
a^(1/2) > 0 deb kelishamiz (daraja funksiyasi uzluksiz, musbat bo'lsin) → a^(1/2) = √a.  ∎

Xuddi shunday (a^(1/n))ⁿ = a  →  a^(1/n) = ⁿ√a.
Va:  a^(m/n) = a^(m · 1/n) = (a^(1/n))ᵐ = (ⁿ√a)ᵐ.  ∎
(yoki a^(1/n · m) = (aᵐ)^(1/n) = ⁿ√(aᵐ) — ikkalasi teng)
```

> Bu isbot — "ratsional ko'rsatkich ta'rifi tasodifiy emas" degan gap. Qoidalar buzilmasligi
> uchun **yagona** mumkin bo'lgan ta'rif.

### E5
```
x² < 9         →  −3 < x < 3                     (parabola, ildizlar orasida)

### E6

## G. 🔗 AI

### G1 — L2 norm
```
(a) ‖(3, 4)‖ = √(9 + 16) = 5
    ‖(1, 2, 2)‖ = √(1 + 4 + 4) = 3
    ‖(1, 1, 1, 1)‖ = √4 = 2
(b) (3, 4)/5 = (0.6, 0.8);   ‖(0.6, 0.8)‖ = √(0.36 + 0.64) = 1 ✓
(c) n ta 1:  √(1 + 1 + ... + 1) = √n.   n = 64 → 8.   n = 512 → √512 = 16√2 ≈ 22.6
```

### G2 — `1/√d_k`
```
(a)  d:      64      128      256      512      4096
     √d:      8      11.31     16      22.63     64
     1/√d:  0.125   0.0884   0.0625   0.0442   0.0156

(b)  [64, 16, 0] / 8 = [8, 2, 0]

(c)  q·k = q₁k₁ + q₂k₂ + ... + q_d k_d — d ta hadning yig'indisi. Har had ~±1.
     Agar hammasi bir tomonga bo'lsa yig'indi ~d bo'lardi, lekin ular tasodifiy
     ishorali — ko'pi bir-birini yo'qotadi. Qolgan "muvozanatsizlik" ~√d.
     (Aniq: variance qo'shiladi → d, std = √d. Ehtimollar mavzusida isbot.)
     Demak ballarning tipik o'lchami √d, uni √d ga bo'lsak ~1 → softmax to'yinmaydi.
     d ga bo'lsak — ballar juda kichik bo'lib, softmax tekislashib ketardi.
```

### G3 — He init

### G4 — RMS
```

(b)  x' = (1, −2, 2, 4)/2.5 = (0.4, −0.8, 0.8, 1.6)

### G5 — LR schedule
```
(a)  t = 1:      0.1/1 = 0.1
     t = 4:      0.1/2 = 0.05
     t = 100:    0.1/10 = 0.01
     t = 10 000: 0.1/100 = 0.001

(b)  0.1/√t < 0.001  →  √t > 100  →  t > 10 000

(c)  t = w = 4000:  t^(−0.5) = w^(−0.5)  va  t·w^(−1.5) = w·w^(−1.5) = w^(−0.5) — teng.
     η = d^(−0.5) · w^(−0.5) = (d·w)^(−0.5) = (512 · 4000)^(−0.5) = 1/√2 048 000 ≈ 1/1431 ≈ 7.0 × 10⁻⁴

(d)  t < w:  t·w^(−1.5) < w^(−0.5) < t^(−0.5)  →  min = t·w^(−1.5) — t ga PROPORSIONAL → O'SADI (warmup)
     t > w:  t^(−0.5) < w^(−0.5) < t·w^(−1.5)  →  min = t^(−0.5) — KAMAYADI (inverse sqrt decay)
     Grafik: chiziqli ko'tarilish, cho'qqi t = w da, keyin 1/√t bo'yicha tushish.
```
