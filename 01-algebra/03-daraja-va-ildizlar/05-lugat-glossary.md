## Daraja / Powers

| O'zbekcha | English | Belgi |
|-----------|---------|-------|
| Daraja | Power | `aⁿ` |
| Asos | Base | `a` in `aⁿ` |
| Ko'rsatkich | Exponent | `n` in `aⁿ` |
| Darajaga ko'tarish | Exponentiation / raising to a power | |
| Kvadrat | Square | `a²`, "a squared" |
| Kub | Cube | `a³`, "a cubed" |
| n-darajasi | n-th power | "a to the n-th" / "a to the n" |
| Natural ko'rsatkich | Natural (positive integer) exponent | |
| Nol ko'rsatkich | Zero exponent | `a⁰ = 1` |
| Manfiy ko'rsatkich | Negative exponent | `a⁻ⁿ = 1/aⁿ` |
| Ratsional (kasr) ko'rsatkich | Rational (fractional) exponent | `a^(m/n)` |
| Teskari son | Reciprocal | `1/a = a⁻¹` |
| Daraja xossalari | Laws of exponents / exponent rules | |
| Ko'paytma qoidasi | Product rule | `aᵐaⁿ = aᵐ⁺ⁿ` |
| Bo'linma qoidasi | Quotient rule | `aᵐ/aⁿ = aᵐ⁻ⁿ` |
| Darajaning darajasi | Power of a power | `(aᵐ)ⁿ = aᵐⁿ` |
| To'la kvadrat | Perfect square | 1, 4, 9, 16, ... |
| To'la kub | Perfect cube | 1, 8, 27, 64, ... |
| Ikkining darajalari | Powers of two | 1, 2, 4, 8, ... |
| O'nning darajalari | Powers of ten | 10, 100, 1000, ... |

## Ildizlar / Roots

| O'zbekcha | English | Belgi |
|-----------|---------|-------|
| Ildiz | Root | `ⁿ√a` |
| Kvadrat ildiz | Square root | `√a` |
| Kub ildiz | Cube root | `³√a` |
| n-darajali ildiz | n-th root | `ⁿ√a` |
| Ildiz ostidagi ifoda | Radicand | `a` in `√a` |
| Ildiz belgisi | Radical sign | `√` |
| Ildiz ko'rsatkichi (indeks) | Index (of the root) | `n` in `ⁿ√` |
| Arifmetik ildiz | Principal root | `√16 = 4`, not −4 |
| Irratsional son | Irrational number | `√2`, `π` |
| Ratsional son | Rational number | `p/q` |
| Ildizni soddalashtirish | Simplifying a radical | `√50 = 5√2` |
| Ko'paytuvchini ildizdan chiqarish | Extracting a factor from a radical | |
| Ko'paytuvchini ildiz ostiga kiritish | Bringing a factor under the radical | `2√3 = √12` |
| Maxrajdagi irratsionallikdan qutulish | Rationalizing the denominator | `1/√2 = √2/2` |
| Qo'shma ifoda | Conjugate | `√3 − 1` ↔ `√3 + 1` |
| O'xshash ildizlar | Like radicals | `2√3 + 3√3 = 5√3` |
| Juft / toq ildiz | Even / odd root | |
| Begona ildiz | Extraneous root | (tenglama yechishda) |

## 📐 O'qilishi / How to read aloud

| Yozuv | O'zbekcha | English |

| `a²` | a kvadrat | "a squared" |
| `a³` | a kub | "a cubed" |

| `a⁻¹` | a minus birinchi darajada | "a to the minus one" / "a inverse" |

| `³√a` | a dan kub ildiz | "cube root of a" |

| `1e-5` | bir e minus besh | "one e minus five" |
| `‖v‖` | v ning normasi | "norm of v" |
| `2⁻²³` | ikki minus yigirma uchinchi darajada | "two to the minus twenty-three" |
