## F. 🔗 AI bilan bog'liq masalalar

> Bu blok — bugungi algebra bilan machine learning orasidagi ko'prik.
> Hech bir yangi bilim kerak emas, faqat shu mavzudagi narsalar.

### F1 ⭐⭐⭐ — Chiziqli regressiya (normal tenglamalar)

Bizda 3 ta nuqta bor: `(1, 2)`, `(2, 3)`, `(3, 5)`.
Ularga `y = wx + b` to'g'ri chizig'ini "eng yaxshi" moslashtirmoqchimiz. "Eng yaxshi"
degani — xatolar kvadratlari yig'indisi minimal:

```
S(w, b) = Σ (w·xᵢ + b − yᵢ)²
```

Matematik tahlil (calculus) shuni beradiki, minimum quyidagi sistemani yechishdan
chiqadi (**normal tenglamalar**):

```
⎧ w·Σx² + b·Σx = Σxy
⎩ w·Σx  + b·n  = Σy
```

**(a)** `Σx`, `Σx²`, `Σy`, `Σxy`, `n` ni hisobla.
**(b)** Sistemani yoz va qo'lda yech → `w` va `b` ni top.
**(c)** Har bir nuqta uchun `yᵢ − (w·xᵢ + b)` qoldiqni hisobla. Ularning yig'indisi nechchi?
**(d)** Javobni `code/03_ai_bogliqlik.py` bilan tekshir.

> Bu — **sen hozir linear regression modelini qo'lda o'rgatding**. `sklearn` ichida
> aynan shu sistema yechiladi (faqat matritsa ko'rinishida: `XᵀX w = Xᵀy`).

### F2 ⭐⭐⭐ — Gradient descent qachon yaqinlashadi (learning rate)

`f(x) = 3x²` funksiyasini minimallashtirmoqchimiz. Gradient descent qadami:

```
x_{k+1} = x_k − η · f'(x_k),      f'(x) = 6x
```

**(a)** `x_{k+1}` ni faqat `x_k` va `η` orqali yoz. (Ko'rinish: `x_{k+1} = c · x_k`)
**(b)** Ketma-ketlik nolga yaqinlashishi uchun `|c| < 1` bo'lishi kerak.
Bundan `η` uchun **tengsizlik** yoz va yech.
**(c)** `η = 0.5` bo'lsa nima bo'ladi? `x₀ = 1` dan boshlab 4 qadam hisobla.
**(d)** Umumiy holda `f(x) = (a/2)x²` uchun shartni chiqar.

> Bu — **learning rate nima uchun juda katta bo'lsa model "portlaydi"** degan
> savolning to'liq matematik javobi. Butun isbot — bitta tengsizlik.

### F3 ⭐⭐ — Cosine similarity chegarasi

`u = (3, 4)`, `v = (4, 3)` vektorlari berilgan.

**(a)** `u · v` (skalyar ko'paytma) ni hisobla.
**(b)** `‖u‖ = √(3² + 4²)` va `‖v‖` ni hisobla.
**(c)** `cos(θ) = (u·v)/(‖u‖·‖v‖)` ni hisobla.
**(d)** Koshi–Shvarts tengsizligini shu sonlar uchun tekshir: `(u·v)² ≤ ‖u‖²·‖v‖²`
**(e)** Qanday `u`, `v` uchun `cos(θ) = 1` bo'ladi? Buni tengsizlikdagi **tenglik holati**
bilan bog'la.

### F4 ⭐⭐ — ReLU tenglamasi

`ReLU(z) = max(0, z)`. Bu — modul kabi **bo'lakli** funksiya:

```
              ⎧ z,  agar z > 0
ReLU(z)  =    ⎨
              ⎩ 0,  agar z ≤ 0
```

**(a)** `ReLU(2x − 6) = 4` tenglamani yech.
**(b)** `ReLU(2x − 6) = 0` ni qanoatlantiruvchi **barcha** x ni top (bu tengsizlik!).
**(c)** `ReLU(2x − 6) = −1` ning yechimi bormi? Nega?
**(d)** `ReLU(z)` ni `|z|` orqali ifodala.
> Ishora: `max(0, z)` va `(z + |z|)/2` ni bir nechta z uchun solishtir.

### F5 ⭐⭐⭐ — Gradient clipping

Training paytida gradient juda katta bo'lsa, uni "kesib" qo'yishadi:

```
agar ‖g‖ > c  bo'lsa:   g  ←  c · g / ‖g‖
aks holda:              g  ←  g
```

`g = (6, 8)`, `c = 4` berilgan.

**(a)** `‖g‖ = √(6² + 8²)` ni hisobla.
**(b)** Clipping ishga tushadimi? (Tengsizlikni tekshir.)
**(c)** Kesilgan gradient `g'` ni hisobla.
**(d)** `‖g'‖` ni hisobla. Nimaga teng chiqdi?
**(e)** Umumiy holda isbotla: clipping'dan keyin **har doim** `‖g'‖ ≤ c`.
