## Asosiy tushunchalar / Core concepts

| O'zbekcha | English | Belgi / izoh |
|-----------|---------|--------------|
| Funksiya | Function | `f`, `f(x)` |
| Argument / kirish | Argument / input | `x` |
| Qiymat / chiqish | Value / output | `f(x)`, `y` |
| Aniqlanish sohasi | Domain | `D(f)` |
| Qiymatlar sohasi | Range | `E(f)` (inglizcha ba'zan `R(f)`) |
| Moslik | Mapping / correspondence | `x ↦ f(x)` |
| Bir qiymatli | One-to-one / injective | har xil x → har xil y |
| Vertikal chiziq testi | Vertical line test | funksiya ekanligini tekshirish |
| Gorizontal chiziq testi | Horizontal line test | bir qiymatli ekanligini tekshirish |
| Grafik | Graph | `{(x, f(x))}` |
| Nuqta | Point | `(x, y)` |
| Koordinata | Coordinate | |
| Koordinata boshi | Origin | `(0, 0)` |
| Abssissa / ordinata | x-coordinate / y-coordinate | |
| Kesma (o'q bilan) | Intercept | x-intercept, y-intercept |
| Nol (funksiyaning) | Zero / root | `f(x) = 0` |

## 📐 Yozuvlar / Notation

| Yozuv | O'qilishi (uz) | Reading (en) |
|-------|----------------|--------------|
| `f(x)` | f dan x | "f of x" |
| `f: A → B` | f A ni B ga akslantiradi | "f maps A to B" |
| `x ↦ x²` | x x-kvadratga o'tadi | "x maps to x squared" |
| `f∘g` | f kompozitsiya g | "f composed with g" |
| `f⁻¹` | f teskari | "f inverse" |
| `D(f)` | f ning aniqlanish sohasi | "domain of f" |
| `E(f)` | f ning qiymatlar sohasi | "range of f" |
| `ℝ \ {2}` | 2 dan tashqari barcha haqiqiy sonlar | "reals minus 2" |
| `σ(x)` | sigma x | "sigmoid of x" |
| `max(a, b)` | a va b dan kattasi | "max of a and b" |
